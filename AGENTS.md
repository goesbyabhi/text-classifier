# AGENTS.md — text-classifier

Zero-shot text classification over plain HTTP, modeled on classifier.dev
(https://github.com/mrmps/classifier-dev): text + labels in, a label and a
calibrated confidence out. Built as a **Cloudflare Python Worker**, not the
TS Worker of the reference.

STATUS: classify path end-to-end. The request-time scorer, embedder
abstraction, Durable-Object limiter, GET/POST routing (path-form AND query
form at bare /), analytics, calibration fitter, eval harness and CLI are
written. There is also a browser landing page (`src/home.py`) with a live
demo box, served from the single canonical `src/docs.py` plain-text document
so the two cannot drift; `GET /` serves HTML to browsers (Accept: text/html)
and the same text to curl. Handlers/wrappers: HN front-page bucketing,
support-email triage with a human double-check flag, the agent-context
result filter, and multi-label changelog tagging — each runnable offline
(hash-v0 stand-in) or against a live endpoint (`examples/`). Discovery
surfaces, mirroring the reference: `GET /benchmark` (measured numbers, served
from a generated `src/benchmark_data.py` so they can only come from eval/,
falling back to an honest stub), the RFC-8615 agent skill at `GET /skill.md`
plus `GET /.well-known/agent-skills/index.json` (v0.2.0, `$schema` + sha256 of
the served bytes — `src/skill.py`), and a stdlib MCP server (`mcp/`)
exposing one `classify_texts` tool. Pure modules pass `uv run pytest` (70
tests). The Worker boots under `uv run pywrangler
dev --local`: /health, GET / (HTML to browsers, text to curl), GET routing
404s bare words, and both GET spellings route to classify correctly. The
classify call itself returns the designed 502 in local dev, because the AI
binding is reported "not supported" locally — the scorer math is covered by
pytest instead.

Deployed (account 750849c8...): https://text-classifier.abxisxekpanda.workers.dev.
Calibration is fit on the REAL frozen bge embedder via Workers AI
(`scripts/train_bge.py`, OAuth token from the wrangler config — no secrets in
repo). Fit on 44 calibration records, NLL 0.826 at temperature 0.100;
multi-label bias 1.536, temperature 0.548, threshold 0.142 (train F1 0.69).
Judged on the 15-record eval holdout: single accuracy 0.70, reliability 0.40,
multi F1 0.08. The poor multi transfer is honest: the eval set is a different
task (news topics) than the calibration set (movement commands) and the fit
is tiny — the low threshold just reflects reality. The threshold lesson still
holds: `fit_multi_threshold` co-fits the boundary with the F1 metric because
a fixed 0.5 boundary silently returned F1 0.

Note: `pywrangler dev` needs uv >= 0.12.3; update via the standalone bin at
~/.local/bin (`uv self update`), the Python-Scripts copy at 0.11.32 shadows
it on PATH otherwise.

## Stack (verified against Cloudflare docs)

- Python Workers run on Pyodide/WASM. Top-level module code runs once at
  deploy time (snapshot) — do heavy init at import, not per-request.
- Tooling is `uv run pywrangler dev|deploy` — Wrangler replaced by
  `pywrangler` for Python. Use `uv` for all env/dep management.
- Package versions are pinned by compatibility date in `pyproject.toml`.
  Keep `compatibility_date >= 2026-09-08` (Python 3.14). numpy (1.26.4),
  FastAPI, Pydantic, httpx are available as WASM wheels; no torch/transformers.

## Model approach (intent — the novel part)

Frozen pretrained sentence embeddings + a request-time linear scorer
(prototypical-style similarity/linear read), calibration fit on a holdout in
`eval/`. No fine-tuning, no per-request training of heavy weights. Design it so
reported confidence is honest: that is the property the reference spent the
most effort on. Keep it numpy-pure so it runs inside the Worker.

- Baseline first: get the classify path working end-to-end, then judge the
  math on eval numbers, not feel.
- `eval/` must pin exactly how a number was measured; never type a measured
  number into docs by hand.

## Conventions

- Docs/landing page: one Markdown source of truth; plain-text and HTML render
  from it so they can't drift (mirrors reference's src/docs + src/home).
- No request text is ever logged or stored; Analytics writes tier/labels/
  status/latency only.
- Never commit secrets: `wrangler.toml`, `.dev.vars` are gitignored; secrets
  go in via `wrangler secret put` / the dashboard.
- Rate limiting lives in a Durable Object (KV is eventually-consistent, the
  platform `ratelimit` binding was abandoned upstream — don't bring either back).
- GET / is the home page, but a query string carrying labels/text at bare /
  routes to classify first (`has_classify_query`), so the query-form GET never
  settles on the docs.
- Measured numbers are only ever served from a *generated* module
  (`src/benchmark_data.py`, written by train_bge.py from eval/results); the
  tracked `src/benchmark.py` holds the pure renderer + fallback stub, so
  nothing is hand-typed into docs. Same shape as the calibration story.
- Agent skills: ONE markdown artifact (`SKILL` in `src/skill.py`), served
  verbatim at /skill.md, with the index's `sha256:` digest computed from the
  exact bytes served so the two can never drift.
- Commands: `uv run pytest` (tests), `uv run pywrangler dev` (local),
  `uv run pywrangler deploy`.
